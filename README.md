# 한판 (HANPAN)

> 게임 알려주고, 배우고, 같이하고 — 온라인으로도, PC방에서 만나서도

https://www.levelmate.co.kr

PC와 모바일이 **같은 코드로 동작하는 PWA**입니다.
PC방 PC에서는 브라우저의 "앱으로 설치"로 바탕화면 아이콘이 생기고,
휴대폰에서는 홈 화면에 추가하면 앱처럼 실행됩니다.

## 서비스 구조

글이 두 개의 축으로 분류됩니다.

**유형**
| | 뜻 |
| --- | --- |
| 알려드려요 | 내가 잘하는 게임을 가르쳐 줍니다 |
| 알려주세요 | 이 게임을 배우고 싶어요 |
| 같이해요 | 함께 즐길 사람을 찾아요 |

**방식** — 온라인으로만 / 만나서(제휴 PC방) / 둘 다

참가비는 무료도 됩니다. 같이 게임할 사람을 찾는 글은 대개 무료입니다.

## 약속 이행 점수

이 서비스의 핵심 신뢰 지표입니다. 지킴·지각·임박취소·노쇼를 가중 평균해
0~100으로 환산하고, 기록이 없으면 `신규`로 표시합니다.

```
점수 = (지킴×1.0 + 지각×0.6 + 임박취소×0.3 + 노쇼×0) / 전체 × 100
```

예약을 완료·노쇼·취소로 처리하면 당사자 지표가 즉시 바뀌고,
카드·상세·프로필·관리자 목록 어디서나 같은 배지로 보입니다.

## 화면

| 경로 | 설명 |
| --- | --- |
| `/` | 홈 — 유형·방식·지역 필터, 글 목록 |
| `/search` | 찾기 — 검색 + 유형·게임·지역·무료 필터 |
| `/listings/new` | 글쓰기 |
| `/listings/[id]` | 글 상세 + 신청(날짜·시간·시간수·방식) |
| `/bookings` | 예약 — 수락·거절·체크인·완료·노쇼, PC방 체크인 코드 |
| `/chat`, `/chat/[id]` | 예약별 대화방 (연락처 노출 없이) |
| `/my` | 프로필 수정, 내 약속 점수, 내 글 |
| `/users/[id]` | 상대 프로필 |
| `/login` | 휴대폰 인증 (실연동 전 임시 흐름) |
| `/admin` | 현황 / 회원 관리 / 정산 |
| `/offline` | 네트워크가 끊겼을 때 서비스 워커가 보여주는 화면 |

관리자 화면은 `role === 'ADMIN'` 계정만 열립니다.
예시 데이터의 관리자 번호는 `010-0000-0000` 입니다.

## 프로필 이미지

사진이 등록되기 전에는 **코드로 그리는 캐릭터 아바타**가 자리를 채웁니다
(`components/avatar-illustration.tsx`). 사용자마다 고정된 값에서 머리·눈·표정·
소품이 정해져, 같은 사람은 항상 같은 얼굴이 나옵니다.

검수를 통과한 사진(`photoStatus === 'APPROVED'`)이 있으면 그 자리를 사진이
대신합니다 — `components/user-art.tsx` 한 곳만 보면 됩니다.

## 데이터

데이터는 전부 **서버(PostgreSQL)** 에 있습니다. 어느 기기로 접속해도 같은 것이
보이고, 여러 사람이 같이 씁니다.

흐름은 한 방향입니다.

1. `app/layout.tsx` 가 요청마다 화면 한 벌(`lib/server/snapshot.ts`)을 만들어 내려보낸다
2. `lib/store.ts` 가 그것을 받아 담는다 — 화면은 이 저장소만 본다
3. 무언가 바꾸면 `/api/action` 으로 보내고, 서버가 바꾼 뒤 새 한 벌을 돌려준다

보는 사람에 따라 담기는 게 다릅니다. 남의 예약과 대화는 아예 내려가지 않고,
휴대폰 번호는 본인·관리자에게만 원문으로 갑니다.

| 파일 | 하는 일 |
| --- | --- |
| `prisma/schema.prisma` | 표 정의. `lib/types.ts` 와 1:1로 맞춰져 있다 |
| `lib/server/snapshot.ts` | 보는 사람 기준으로 화면 한 벌을 만든다 |
| `lib/server/actions.ts` | 모든 변경과 권한 검사가 여기 모여 있다 |
| `lib/server/auth.ts` | 세션 쿠키, 비밀번호 해시(scrypt) |
| `lib/store.ts` | 화면이 쓰는 저장소. 서버 호출을 감싼다 |
| `prisma/seed.mjs` | 첫 실행 때만 채우는 예시 데이터 + 관리자 계정 |

화면은 15초마다, 그리고 다른 일 하다 돌아왔을 때 서버에서 데이터를 다시 받아옵니다.
켜둔 채로도 새 글·새 회원·새 메시지가 들어옵니다.

프로필 사진도 DB(`Photo` 표)에 담깁니다. `docs/photos.md` 참고.

## 기술 스택

- Next.js 16 (App Router, Turbopack) / React 19
- TypeScript, Tailwind CSS v4
- PostgreSQL + Prisma 7 (`@prisma/adapter-pg`)
- PWA: `app/manifest.ts` + `public/sw.js`

## 실행

PostgreSQL 이 필요합니다. `.env.example` 을 `.env` 로 복사해 `DATABASE_URL` 을 채운 뒤:

```bash
npm install
npx prisma migrate deploy   # 표 만들기
node prisma/seed.mjs        # 예시 데이터 + 관리자 계정(levelup/levelup)
npm run dev                 # http://localhost:3000
```

```bash
npm run build && npm start   # 프로덕션 빌드
npm run lint                 # ESLint
npm run icons                # 로고 변경 시 PWA 아이콘 재생성
```

## PC방 설치 안내

1. 브라우저(크롬/엣지)로 https://www.levelmate.co.kr 접속
2. 주소창 오른쪽 설치 아이콘 또는 메뉴 → **앱으로 설치**
3. 바탕화면에 생긴 **한판** 아이콘으로 실행

> PC방 PC는 복원 솔루션이 걸린 경우가 많아 재부팅하면 설치가 사라질 수 있습니다.
> 매장 배포 시에는 관리자 이미지에 바로가기를 포함시키는 방식을 권장합니다.

웹폰트·아이콘·이미지를 전부 시스템 자원과 인라인 SVG로 처리해, 외부 CDN이
막힌 매장에서도 화면이 깨지지 않습니다.

## 디렉터리

