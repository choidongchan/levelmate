# 레벨메이트 (LevelMate)

> 게임 친구가 필요할 때 — PC방 기반 게임 동행 매칭 플랫폼

PC와 모바일에서 **같은 코드로 동작하는 PWA**입니다.
PC방 PC에서는 브라우저의 "앱으로 설치"로 **바탕화면 아이콘**이 생기고,
휴대폰에서는 **홈 화면에 추가**로 앱처럼 실행됩니다.

## 현재 상태

1차 UI 프로토타입입니다. 데이터는 `lib/data.ts`의 더미 값이고, 로그인·결제·DB는 아직 없습니다.

구현된 화면

| 경로 | 설명 |
| --- | --- |
| `/` | 홈 — 지역 선택, 배너, 동행 상품, 추천 메이트, 이용 방법, 안심 안내, 제휴 PC방 |
| `/search` | 메이트 검색 — 게임/온라인 필터, 평점·가격·후기순 정렬 |
| `/mates/[id]` | 메이트 상세 — 가능 시간, 주요 게임, 동행 PC방, 소개, 예약 바 |
| `/bookings`, `/chat`, `/my` | 탭 자리표시 화면 |
| `/offline` | 오프라인일 때 서비스 워커가 보여주는 화면 |

## 기술 스택

- Next.js 16 (App Router, Turbopack) / React 19
- TypeScript, Tailwind CSS v4
- PWA: `app/manifest.ts` + `public/sw.js`

## 실행

```bash
npm install
npm run dev      # http://localhost:3000
```

```bash
npm run build && npm start   # 프로덕션 빌드
npm run lint                 # ESLint
npm run icons                # 로고 변경 시 PWA 아이콘 재생성
```

## PC방 설치 안내

1. 브라우저(크롬/엣지)로 서비스 주소를 연다
2. 주소창 오른쪽 설치 아이콘 또는 메뉴 → **앱으로 설치**
3. 바탕화면에 생긴 **레벨메이트** 아이콘으로 실행

> PC방 PC는 복원 솔루션이 걸린 경우가 많아 재부팅하면 설치가 사라질 수 있습니다.
> 매장 배포 시에는 관리자 이미지에 바로가기를 포함시키는 방식을 권장합니다.

웹폰트·아이콘·이미지를 전부 인라인/시스템 자원으로 처리해 외부 CDN이 막힌 매장에서도 화면이 깨지지 않습니다.

## 디렉터리

```
app/          라우트 (App Router)
components/   공용 UI
lib/          더미 데이터·포맷 유틸
public/       서비스 워커, PWA 아이콘
scripts/      아이콘 생성 스크립트
```
