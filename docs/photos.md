# 프로필 사진

사진을 넣는 방법은 두 가지입니다. **보통은 1번을 씁니다.**

## 1. 관리자 화면에서 올리기 (권장)

관리자 → 회원 → 해당 회원 `수정` → **사진 선택**

파일을 고르면 편집 창이 뜹니다. 끌어서 위치를 잡고 확대·축소해서 3:4 칸을
꽉 채운 뒤 `이대로 사용`을 누르면, 그 부분만 720×960 WebP 로 잘려 서버에 저장됩니다.
원본 비율이 어떻든 찌그러지지 않습니다.

- 저장 위치: **DB (`Photo` 표)**. 배포·경로·권한과 무관하게 남고, 매일 도는 백업에도 함께 들어갑니다
- 주소: `/api/photos/<내용지문>.webp` — 내용이 곧 이름이라 캐시를 길게 둡니다
- 관리자가 올리면 바로 노출(`APPROVED`), 본인이 올리면 검수 대기(`PENDING`)

> 파일로 두지 않는 이유가 있습니다. 파일은 저장 경로·권한·배포 방식 중 하나만
> 어긋나도 조용히 사라지는데, 올린 사람 브라우저에는 캐시가 남아 있어서
> **본인 화면만 멀쩡해 보이고 다른 사람 화면에서만 안 보입니다.**
> 알아채기 가장 어려운 고장이라 DB 로 옮겼습니다.

## 회원 본인이 올리기

마이 → 수정 → **사진 선택**. 같은 편집 창이 뜹니다.
본인이 올린 사진은 바로 노출되지 않고 **검수 대기**로 들어가며,
관리자 → **사진 검수** 에서 승인해야 다른 사람에게 보입니다.
그 전까지는 본인 화면에만 보이고, 마이 화면에 "검수 중" 안내가 뜹니다.

## 사진이 안 보일 때

관리자 → 사진 검수 → **서버 보관 상태**. 서버에 실제로 남아 있는지 바로 알려줍니다.
화면에 보인다고 서버에 있는 것이 아니므로, 의심되면 여기서 확인하세요.

## 2. 파일을 저장소에 직접 넣기

`public/mates/` 에 파일을 두고, 회원 수정 화면의 *사진 경로 직접 입력* 칸에
`/mates/파일명.jpg` 를 넣습니다. 예시 회원들이 참조하는 이름은 아래와 같습니다.

| 회원 | 파일명 |
| --- | --- |
| 미드장인 | `midking.jpg` |
| 초보탈출 | `newbie.jpg` |
| 한밤의궁수 | `nightowl.jpg` |
| 코치정 | `coach.jpg` |
| 감자칩 | `potato.jpg` |
| 야근전사 | `overtime.jpg` |
| 단풍잎 | `mapler.jpg` |

파일이 없으면 캐릭터 아바타가 대신 뜨므로, 없어도 화면은 깨지지 않습니다.

권장 규격: 세로형 3:4, 720×960 안팎, 500KB 이하, jpg 또는 webp

## 주의

올리는 사진은 **본인 사진이거나 사용 권리가 확인된 것**이어야 합니다.
실제 서비스에서는 회원이 직접 올린 사진을 관리자가 검수한 뒤 노출합니다
(`photoStatus === 'APPROVED'` 인 것만 화면에 나갑니다).
