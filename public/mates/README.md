# 프로필 사진

여기에 넣은 파일이 메이트 프로필 사진으로 나옵니다.
파일이 없으면 캐릭터 아바타가 대신 뜨므로, 없어도 화면은 깨지지 않습니다.

## 파일 이름

`lib/seed.ts` 의 사용자 id 에서 `u-` 를 뗀 이름 + `.jpg`

| 사용자 | 파일명 |
| --- | --- |
| 미드장인 | `midking.jpg` |
| 초보탈출 | `newbie.jpg` |
| 한밤의궁수 | `nightowl.jpg` |
| 코치정 | `coach.jpg` |
| 감자칩 | `potato.jpg` |
| 야근전사 | `overtime.jpg` |
| 단풍잎 | `mapler.jpg` |

## 권장 규격

- 정사각형 (1:1), 800×800 안팎
- 500KB 이하
- jpg 또는 webp

## 주의

올리는 사진은 **본인 사진이거나 사용 권리가 확인된 것**이어야 합니다.
실제 서비스에서는 회원이 직접 올린 사진을 관리자가 검수한 뒤 노출합니다
(`photoStatus === 'APPROVED'` 인 것만 화면에 나갑니다).
